# 🛡 Telegram Business Assistant Bot 5.0

Умный персональный ассистент для **Telegram Business**, обеспечивающий сохранность важной информации в переписках: фиксацию удалённых и отредактированных сообщений, сохранение самоуничтожающихся медиафайлов и быстрый доступ к ним.

---

## 🔒 Приватность и безопасность данных

> [!IMPORTANT]
> **Полная конфиденциальность ваших данных:**
> * **Изоляция данных**: все сохраняемые сообщения и медиафайлы привязаны исключительно к вашему Telegram ID и обрабатываются строго локально.
> * **Защита от доступа третьих лиц**: доступ к восстановленным медиафайлам и уведомлениям о правках имеет только владелец подключённого бизнес-аккаунта.
> * **Прямая доставка**: бот отправляет уведомления и файлы напрямую в ваш личный диалог с ботом, минуя сторонние сервисы.
> * **Контроль уведомлений**: вы в любой момент можете отключить любые типы оповещений в меню настроек (`/settings`) или отключить бота в настройках Telegram в один клик.

---

## ⚡️ Возможности для пользователей

* 🔄 **Официальное подключение**: быстрая привязка бота к аккаунту через стандартный функционал *Telegram Business* (Настройки → Telegram Business → Чат-боты) без передачи паролей или файлов сессий.
* 🔥 **Сохранение исчезающих медиа (Self-Destruct)**: автоматический перехват фото и видео с таймером просмотра для личного архива.
* ↩️ **Восстановление по ответу (Reply)**: просто ответьте на исчезнувшее сообщение в переписке — и бот моментально пришлёт вам сохранённый оригинал.
* 🗑 **Уведомления об удалении**: если собеседник удалил сообщение из чата, бот пришлёт вам текст и медиафайл удалённого сообщения.
* ✏️ **История изменений**: фиксация редактирования текста («было» / «стало») для прозрачности важных договоренностей.
* ⚙️ **Гибкие настройки (`/settings`)**: раздельное управление оповещениями об удалении и редактировании в удобном интерактивном меню.
* 🎁 **Реферальная программа (`/ref`)**: приглашайте друзей и получайте дополнительные бонусные сохранения за каждое подключение.
* ⭐ **Premium-подписка**: безлимитное восстановление медиафайлов с быстрой и безопасной оплатой через **ЮKassa** (СБП, банковские карты).

## 🏗 Стек технологий

* **Язык**: Python 3.10+
* **Фреймворк**: `aiogram 3.15` (официальный Telegram Business API)
* **База данных**: PostgreSQL 15 Alpine
* **ORM & Драйвер**: `SQLAlchemy 2.0` (async) + `asyncpg`
* **Платежи**: ЮKassa API
* **Контейнеризация**: Docker, Docker Compose

## 🚀 Установка на VPS в одну команду (из GitHub)

Подключитесь к вашему серверу по SSH, перейдите в папку проекта и запустите установку:

```bash
git clone https://github.com/NikSyrovatskij/telegram_log_bot.git . && sudo bash install.sh
```

> **Если папки еще нет, полный запуск с нуля в одну строку:**
> ```bash
> mkdir -p /root/bot && cd /root/bot && git clone https://github.com/NikSyrovatskij/telegram_log_bot.git . && sudo bash install.sh
> ```

Скрипт полностью в автоматическом режиме:
1. Установит `Docker` и `Docker Compose Plugin` (если они не установлены на сервере).
2. Загрузит проект и создаст `.env` из шаблона.
3. Предложит в терминале ввести `BOT_TOKEN` и ваш `ADMIN_ID`.
4. Создаст папку для медиафайлов.
5. Соберёт Docker-образ и запустит контейнеры в фоновом режиме.

## 📦 Пошаговая ручная установка (альтернативный способ)

Если вы настраиваете сервер вручную:

### 1. Установите Docker:
```bash
sudo apt-get update && sudo apt-get install -y curl git ca-certificates gnupg
curl -fsSL https://get.docker.com | sh
sudo systemctl enable docker && sudo systemctl start docker
sudo apt-get install -y docker-compose-plugin
```

### 2. Настройте конфигурацию:
```bash
cp .env.example .env
nano .env
```
*(Укажите токен бота, ID администратора и ключи ЮKassa).*

### 3. Запустите проект:
```bash
docker compose up -d --build
```

## ⚙️ Настройка файла переменных (.env)

| Переменная | Назначение | Пример |
|---|---|---|
| `BOT_TOKEN` | Токен Telegram-бота от [@BotFather](https://t.me/BotFather) | `123456789:ABCdef...` |
| `ADMIN_ID` | Telegram ID технического администратора (для системных задач) | `123456789` |
| `DATABASE_URL` | Подключение к базе данных в Docker-сети | `postgresql+asyncpg://log_user:log_pass@db:5432/log_db` |
| `START_ATTEMPTS` | Начальный баланс бесплатных сохранений | `3` |
| `REFERRAL_BONUS` | Бонус сохранений за приглашенного друга | `1` |
| `YOOKASSA_SHOP_ID` | Идентификатор магазина ЮKassa | `123456` |
| `YOOKASSA_SECRET_KEY` | Секретный ключ ЮKassa | `live_xxxxxxxxx` |
| `PRICE_30_DAYS` | Стоимость 30 дней Premium (в копейках: 10000 = 100 руб.) | `10000` |
| `PRICE_60_DAYS` | Стоимость 60 дней Premium (в копейках: 17000 = 170 руб.) | `17000` |
| `PAYMENT_CHECK_INTERVAL` | Интервал проверки платежей (секунды) | `30` |

## 🤖 Подключение бота в Telegram

1. Откройте [@BotFather](https://t.me/BotFather) и создайте нового бота (`/newbot`).
2. Скопируйте полученный токен в `.env`.
3. **Включите поддержку Telegram Business**:
   * Напишите `/mybots` → выберите вашего бота.
   * Перейдите в **Bot Settings** → **Business Mode** → **Turn On**.
4. **Подключите бота к аккаунту**:
   * В приложении Telegram перейдите: **Настройки** → **Telegram Business** → **Чат-боты**.
   * Введите юзернейм вашего бота и подтвердите привязку.

## 📋 Управление контейнерами

Все команды выполняются в папке с проектом:

```bash
# Просмотр логов работы бота:
docker compose logs -f bot

# Перезапуск сервисов:
docker compose restart

# Остановка бота:
docker compose down

# Проверка статуса контейнеров:
docker compose ps
```
